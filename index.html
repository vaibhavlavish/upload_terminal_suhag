Prompt

This is what's sent to the AI along with the photo. The default below applies unless you change it — tweak it here for just this one attempt, or save it as the new default for every future generation.

Optional placeholders — swapped in automatically per item before generating, using its resolved Tag Manage details (tag override → group default): {{NAME}}, {{SIZE}} (only fills in if Display Size is on for that category), {{WIDTH}}, {{REMARKS}} (e.g. put "8mm wide chain" in Remarks for a specific tag). These four are the only ones offered because they're the only fields that describe how something should actually look. Important: these are context to help the AI understand true scale/proportion — never instructions to design or replace the piece. The uploaded photo is always the ground truth for what the jewelry actually looks like.
